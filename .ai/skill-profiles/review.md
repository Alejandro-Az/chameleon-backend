# Skill Profile · Review

## Skills

Base:
- laravel-specialist
- php-pro

Contextuales según revisión:
- eloquent-best-practices
- laravel-tdd
- php-best-practices

## Cuándo usarlo

Usar este profile cuando la tarea implique:

- code review
- revisión de arquitectura
- revisión de queries
- revisión de tests
- evaluación de riesgo
- revisión de higiene
- evaluación de impactos cruzados

## Comportamiento esperado

Al usar este profile, el agente debe:

- revisar más allá de si "funciona"
- detectar deuda técnica
- detectar silent drift
- detectar ghost code
- detectar falta de tests
- detectar riesgos de seguridad
- detectar inconsistencias con el core
- cuestionar complejidad innecesaria

## Anti-patterns

No hacer:

- aprobar cambios solo porque compilan
- ignorar impacto en Swagger
- ignorar impacto en integración frontend
- ignorar higiene del repositorio
- ignorar cambios de contrato
